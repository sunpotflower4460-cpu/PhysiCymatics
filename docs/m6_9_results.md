# M6-9 結果: 高周波における接触計算の不安定さの原因切り分け

前提: M6-8（PR #11）を main へ統合済み。本段階は研究が中心で、
本番経路の物理は変更していない（研究用に接触サンプル数の切替
フィールドを追加したのみ。既定値は従来どおり 8）。

再実行方法:
- `PHYSI_BENCH=1 npx vitest run src/simulation/__tests__/study_shallow.test.ts`
- `PHYSI_BENCH=1 npx vitest run src/simulation/__tests__/study_m69.test.ts`
- `PHYSI_BENCH=1 npx vitest run src/simulation/__tests__/study_m69b.test.ts`

## 確定したこと

### 1. 8サンプル方式の見逃しは、測った範囲では観測されなかった

- 1セグメント内の稠密参照（800点）との比較: 共鳴級の振幅を含む
  22,000 件の近接軌道で、8サンプルが見逃した接触は 0 件。
- 実シミュレーション内でサンプル数を 8 → 32 に変えても、649 Hz /
  1,241.6 Hz ともに衝突・離脱回数は完全一致した。

つまり spp（時間刻み）を変えたときの衝突回数の変化は、
サンプリングの見逃しでは説明できない。

### 2. 最初の接触時刻は時間刻みに依存しない

あらかじめ励振した板への最初の衝突時刻は、spp=44 と 176 で
1 µs 表示まで一致した（649 Hz / 1,241.6 Hz、6 粒子ずつ）。
初期の局所誤差は小さく、回数の差はその後の多数の接触を通じて
増幅されたものと判断できる。

### 3. 板表面の時間表現そのものが刻みに依存する

【M6-9R訂正】下記の「最大約140µm」は比較時刻のずれによる誤りだった。
正しくは最大約1.3µm。詳細は末尾の「M6-9R 再検証による訂正」を参照。
本節の元の文章は記録として残す。

全モード励振・自由減衰で、板の高さを共通時刻で比べたところ、
spp=44 と spp=352 で最大約 140 µm の差があった（152 Hz 駆動の
刻み条件。細かくするほど単調に縮小）。原因は2つ:

- Hermite 補間の区間長が駆動周波数で決まるため、駆動より高い
  モードでは区間が周期の大きな割合を占め、補間誤差が増える。
- RK4 の内部刻みは上限で決まるが、区間長に応じた丸めで実効刻みが
  変わり、位相が少しずつずれる。

中心駆動の通常条件では生きているモードが 152/649 Hz のみで
影響は小さいが、偏心駆動や周波数変更後の残留振動では効く。
この「表面そのものの差」が接触時刻を微小にずらし、多数の
跳ね返りを通じて回数差（649 Hz で約 2%、1,241.6 Hz では未収束）
に増幅されると結論する。

### 4. 空間離散化（動径ビン）には実在の不連続がある

実装の板高さは動径ビン境界で不連続に跳ぶ。全モード励振
（|q|〜2e-4）での最大の跳びは約 3.9 µm。モードごとの隣接ビン差は
最大 0.014。Python 参照実装も同じビン方式であり、これは
実装差ではなくモデル共通の性質である。通常の連続関数を前提と
する根探索をそのまま「厳密」とは呼べない理由になるが、二分探索は
符号変化点へ収束するため実害は浅い接触の境界付近に限られる。

## まだ特定できていないこと

- 1,241.6 Hz で刻みを細かくしても回数が収束しない内訳
  （表面表現差と軌道のカオス的増幅の配分）。
- 真の連続衝突検出を参照とした場合の、見逃しの絶対量。
  本研究の稠密参照（800点）自体にも理論上は見逃し余地が残る。
- 表面表現の刻み依存を下げる方法（区間長を最高モード基準にする等）は
  Python 参照との一致を変えるモデル変更であり、未評価。

## 採用・不採用

- 本番経路の変更: なし（研究用切替 `contactSamples` の追加のみ、
  既定 8 で従来と同一動作）。
- 包含判定による高精度接触検出（CCD）: 今回は実装しなかった。
  理由は、見逃しが観測されず、観測された不安定さの主因が
  検出方式ではなく表面の時間表現にあるため。CCD を入れても
  spp 感度は解消しない見込みが高い。
- 次に有効な研究: 板の時間表現の解像度を駆動周波数から切り離す
  方式（Python 参照と同時変更＋オラクル再検証が必要なモデル変更）、
  および包含判定 CCD を「見逃し量の測定器」として先に作ること。

## テスト・ブラウザ

- Web 75 件通過（研究・ベンチ 6 件は環境変数なしでスキップ）、ビルド成功。
- ブラウザ（ヘッドレス Chrome、単回）: 5,000 粒で 1 Worker ×0.067 /
  8 Worker ×0.375、20,000 粒で ×0.15（8 Worker）。計測環境の負荷で
  絶対値は変動する。物理時刻と描画は分離して記録した。
- Python: 参照実装は無変更。本研究の結論（ビン方式・刻み方式の共通性）は
  Python 側の実装を読んで確認した。

# M6-9R 再検証による訂正（2026-11-03）

再実行方法:
- `PHYSI_BENCH=1 npx vitest run src/simulation/__tests__/study_m69c.test.ts`
- `PHYSI_BENCH=1 npx vitest run src/simulation/__tests__/study_m69d.test.ts`
- 比較時刻の回帰テスト（常時実行）: 同ファイル内
  `m69c comparison-time regression`

## 訂正1: 「最大約140µm」は測定方法の誤り。実際は約1.3µm

元の実験A2は `surfAt(x, y, tEnd - 0.37*dt)` で評価しており、`dt` が
sppに依存するため、比較対象の絶対時刻が最大約48µs（152Hz）ずれていた。

- 欠陥のある方法をそのまま再実行すると 1.41e-4 m（約140µm）が再現する
  → 元の数値の正体は時刻ずれ。
- 全方式で共通の絶対時刻格子（dt44/4間隔、同一のFloat64値）で再測定
  した結果（全モード励振＋駆動、物理0.01秒、40点、vs spp=352）:

| 駆動 | spp=44 | spp=88 | spp=176 |
|---:|---:|---:|---:|
| 152Hz | 1.30e-6 m | 7.5e-7 m | 7.5e-7 m |
| 649Hz | 6.2e-7 m | 3.8e-8 m | 2.3e-9 m |
| 1241.6Hz | 4.6e-8 m | 2.9e-9 m | 1.7e-10 m |

つまり板高さの刻み依存差は実在するが、µm級であり、当初の主張の
約100分の1である。§3の結論のうち「高さの差が大きい」という部分は撤回する。

## 訂正2: 一方、板加速度 wtt の刻み依存差は大きい

同じ共通時刻比較で、加速度の最大差（vs spp=352）:

| 駆動 | spp=44 | spp=88 | spp=176 |
|---:|---:|---:|---:|
| 152Hz | 1.42e3 m/s² | 3.5e2 | 8.8e1 |
| 649Hz | 8.8e1 m/s² | 2.0e1 | 4.1 |
| 1241.6Hz | 2.3e1 m/s² | 5.6 | 1.1 |

Hermite 3次補間の2階微分は区間内で線形であり、区間長が駆動周波数で
決まる現行方式では、低周波駆動（長い区間）のもとで高周波モードが
励振されていると、加速度の表現誤差が大きくなる。これは着座粒子の
離脱判定（wtt < -g）の時刻に直接影響し得る。衝突回数の刻み依存は、
「高さ誤差」よりも「加速度（離脱）誤差＋多数回接触による増幅」で
説明する方が整合的である（配分の定量化は未完。下記D1参照）。

## 解析解による誤差分離（自由減衰、独立基準）

外力ゼロの減衰振動子 `q'' + 2ζωq' + ω²q = 0` の解析解と比較した
（152Hz刻み条件、全自由度励振、物理0.01秒）。

- RK4端点誤差: spp=44/88/176 で同一の 6.6e-7（内部刻み上限
  hMax=0.3/ωmax≈38.5µs により実効刻みが約37.4µsで共通化するため）。
  spp=352（実効18.7µs）では 4.1e-8（4次収束と整合）。
- 純Hermite補間誤差（解析解の端点を与えた場合）: 区間149.5µsで
  7.7e-7、74.8µsで 4.9e-8、37.4µsで 3.1e-9（ほぼ16倍ずつ=4次）。
- 合成した表面高さ誤差（vs解析解）: spp=44で 1.3e-6 m。A3の実測と一致。

結論: 現行spp=44・152Hz条件では、RK4端点誤差とHermite補間誤差が
同程度（各~7e-7）に効いている。sppを88以上に細かくしても高さ誤差が
7.5e-7で頭打ちになるのは、RK4実効刻みが変わらないためである。
駆動あり条件の自己収束（44→88→176の差の比）は 16.0 で4次収束と
整合した（同一方式内の自己整合であり、独立基準は上記の解析解）。

## 動径ビンと勾配の整合性（監査結果）

- 実装上の板高さは半径方向に区分定数（ビン境界は r=k·a/511、
  ビン幅0.235mm）。境界での高さの跳びは全モード励振条件で
  最大 2.9e-6 m（r≈0.116m）。Python参照も同一の床関数ビン参照であり
  モデル共通の性質。
- 接触法線に使う勾配は、実装高さの微分（ビン内では半径方向に厳密に0、
  境界では未定義）ではなく、固有関数の解析微分の標本（dR表）である。
  半径方向成分は最大 9.4e-3（無次元勾配）に達する。接線（角度）方向は
  解析形どおりで、有限差分と 3.1e-11 まで一致した。
- 解釈: 高さは階段状の近似面、法線は滑らかな真のモード形のもの、と
  いう混在モデルになっている。跳び（~3µm）は高さの時間表現誤差
  （~1µm）より大きい。ただし Python/TypeScript 共通の既存モデル
  定義であり、連続補間への変更はモデル変更にあたるため、本段階では
  変更せず研究課題として記録する（M6-10候補）。
- ビン幅の収束（Python `build_basis` で基底を再生成して実測）:
  隣接ビン最大差 |ΔR| は ngrid=512→0.0144、1024→0.0072、
  2048→0.0036 と正確に半減（1次収束、最悪は縁付近の m=4 モード）。
  |q|=2e-4 の単一モード換算の跳びは 2.87µm→1.44µm→0.72µm で、
  TS側の実測 2.9µm と一致する独立確認になった。
