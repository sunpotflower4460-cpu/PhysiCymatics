## 1. 先行課題: 接触面の幾何の不整合

水平力は板の傾き（勾配）と法線で決まる。現在の実装には次の
不整合がある（M6-9Rで確認、M6-13で再測定）:

- 高さは動径ビン（511区間）ごとに一定値へ量子化され、ビン
  境界で最大約2.9µm跳ぶ。
- 接触法線に使う勾配は、その量子化された高さの微分ではなく、
  固有関数の微分 dR の標本である。つまり「実装された面」と
  「法線が指す面」が厳密には別の面。

滑り摩擦の方向は接線方向で決まるため、この不整合は水平運動の
導入前に扱いを決める必要がある。候補:

| 方式 | 長所 | 短所 |
|---|---|---|
| A. 現行のまま（高さ=ビン量子化、勾配=dR標本） | 既存の全保証・結果を維持 | 面と法線の不整合が残る。ビン内では実装高さの動径勾配が0なのに摩擦力は働く |
| B. 高さを連続補間に変更 | 面と勾配が整合 | 物理モデルの数値表現そのものの変更。高さ上限・接触・休止の全証明を再検証する必要がある |

本段階では A を前提に定式化し、不整合の大きさを測定して記録
するに留める。B は独立課題として分離する（勝手に混ぜない）。

## 2. 最小モデル: 曲面上質点のクーロン摩擦

板面をグラフ曲面 z = h(x, y, t) とする。板の物質点はこの
モデルでは鉛直にのみ動く（速度 (0, 0, ∂h/∂t)）。
着座した質点の位置は r = (x, y, h(x,y,t)) に拘束される。

記号: ∇h=(hx,hy)、H=ヘッセ行列、ht=∂h/∂t、htt=∂²h/∂t²、
s=√(1+|∇h|²)、単位法線 n̂=(−hx,−hy,1)/s。

### 垂直抗力（厳密）

拘束から法線方向の加速度は運動学だけで決まる:

    B = q̇ᵀHq̇ + 2(∇ht)·q̇ + htt        (q=(x,y))
    N = m (B + g) / s

- N ≤ 0 が離脱条件。静止・平坦では B=htt=wtt となり、既存の
  離脱条件 wtt < −g と一致する（後方互換の確認点）。
- 曲率項 q̇ᵀHq̇ は「曲面に沿って速く動くと浮く/押し付けられる」
  効果で、省略する場合は大きさを見積もって明記する。

### 接線運動方程式

Lagrange方程式（一般化座標 q）:

    M(q) q̈ + m·(慣性・曲率項) = Q重力 + Q摩擦,   M = I + ∇h∇hᵀ

摩擦は接平面内の3次元力として与える。相対速度は
v_rel = v粒 − (0,0,ht)、その接線成分を v_t とする。

- **静止摩擦（stick）**: v_t = 0（このモデルでは vx=vy=0 と同値）
  を保つのに必要な摩擦力 F_req を運動方程式から逆算し、
  |F_req| ≤ μs·N なら静止を維持する。
- **動摩擦（slip）**: F = −μk·N·(v_t/|v_t|)。
- 飛行中は摩擦なし（既存の弾道）。再接触は既存の衝突処理。

パラメータは μs, μk の2つだけを新規導入する。転がり（回転）は
粒子の形状と慣性モーメントの定義が必要なため本段階では
入れない。既存の経験的転がり項（Python の c_roll 経路）とは
別物として区別する。

## 3. 単粒子検証（採用の関門）

規定した解析的テスト面で次を確認してからでなければ、本体の
砂へ接続しない:

1. 水平な静止板: 自発的な横移動ゼロ（数値ドリフトなし）。
2. 静止傾斜面: 滑り開始が tanθ = μs と一致。
3. 摩擦なし傾斜面: 加速度が理論値 −g·sinθ·cosθ（x成分）と一致。
4. 動摩擦あり傾斜面: g(sinθ − μk·cosθ)（接線加速度）と一致。
5. 鉛直振動する平面: N の符号変化と離脱条件が wtt<−g と一致し、
   静止摩擦の限界が振動で周期的に変わること。
6. 離脱中は摩擦が働かず、再接触後に接触状態へ戻ること。

## 4. 本体接続時に壊れる保証（接続前の棚卸し）

着座粒が水平に動くと、次がそのままでは成立しない:

- 着座休止の証明（固定位置での加速度下限が前提）
- 着座位置の形状関数キャッシュ類
- 「着座中は x,y 不変」を使う表示差分の省略

したがって研究用接続の初版では、摩擦ONの間は着座休止を
無効化し（通常計算へ戻す）、証明は後から再構築する。
既定OFFを維持し、既存経路のビット再現性を壊さない。

## 5. 駆動位置の比較（現モデルでの予備実験）

中心駆動は軸対称モードのみを励起する。偏心駆動で非軸対称
モードが立つか、現モデル（摩擦なし）でも水平輸送の分布が
変わるかを測定する。駆動は物理的外力として与え、模様から
逆算しない。
