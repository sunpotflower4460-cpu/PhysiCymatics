# M6-17 設計 — 振動する曲面上の球転がり

## 目的

M6-16 の静的曲面転がりを、時間依存の曲面 `z=h(x,y,t)` へ拡張する。
本体（砂シミュレーション）へは接続しない。板側には、将来の接続に
必要な動的フィールド（ht, htt の空間微分まで）の評価を追加する。

## 必要な微分（PUT-IN）

中心 C = S + R·n̂（S=(x,y,h)）の二階までの偏微分に必要なもの:

- h の空間三階まで（M6-16 と同じ）
- ht の空間二階まで（htx, hty, htxx, htxy, htyy）
- htt の空間一階まで（htt, httx, htty）

## 導出の要点（EMERGED）

- Ċ = J·q̇ + C_t、C̈ = J·q̈ + A0、
  A0 = Hc(v,v) + 2(C_xt·vx + C_yt·vy) + C_tt
- 法線分離は維持される: **N = n̂·A0 + g·n̂_z**
  （J の列は接線方向のため）。離脱は N≤0。
- 滑り速度 u = J·q̇ + R·n̂_t − R(ω×n̂)
  （板の物質点速度 (0,0,ht) を差し引いた形）。
- u̇ = J·q̈ + K + f/β、
  K = Hc + (0,0,∇ht·v) + 2R(n̂_xt·vx + n̂_yt·vy) + R·n̂_tt
    − R(ω×n̂dot)、n̂dot = n̂_x vx + n̂_y vy + n̂_t。
- 転がりは M6-16 と同じ 4×4 連成系（A0, K に置換）。
  滑りは N を先に決めて f = −μk·N·û。

## 検証計画

1. 中心偏微分（x, y, t 方向）を有限差分と照合。
2. 振動する平面斜面で M6-15 の平面モジュールと軌道一致
   （独立した2つのコード経路の相互照合）。
3. 静的極限（ht=0）で M6-16 の円筒槽周期と一致。
4. 上下振動する槽の底: 振幅が小さい場合は接触維持、
   htt < −g に達する場合は解析位相で離脱。
5. 板の動的フィールドを有限差分（空間・時間）と照合。
