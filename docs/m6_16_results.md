# M6-16 結果 — 静的曲面上の球転がり＋板の三階微分

設計: `docs/m6_16_design.md`。実装:
`webapp/src/simulation/rollingSphereCurved.ts`（研究用、本体未接続）、
板の三階微分 `surfaceThirdConsistent` / `radialInterp3`
（`plateTransient.ts`、整合幾何の研究経路内）。

## 実測（measured）

| 検証 | 結果 |
|---|---|
| 中心 C の偏微分 vs C の直接計算の有限差分（正弦面） | 一階 1e-5、二階 2e-3 以内 |
| 円筒槽（Rc=0.05）の小振動周期 | 解析値 2π√((1+β)(Rc−R)/g) と 1% 以内 |
| 放物面お椀でのエネルギー保存（転がり 1.5 秒） | 相対 1e-6 未満 |
| 正弦面でのエネルギー保存・滑りゼロ維持 | 相対 1e-5 未満 |
| 凸面の頂点での離脱 | N≈g−V²/Rc と整合（速いと離脱、遅いと接触） |
| 平面極限 | M6-15 の斜面加速度と一致（9 桁） |
| 板の三階微分 vs ヘッセ行列の有限差分 | 最大スケール誤差 3.6e-8 |
| 板中心の三階微分 | 方向極限と一致（m=1,3 のみ非ゼロ） |

## 分かったこと・限界

- 静止した曲面なら、転がりの力学は解析・エネルギー・周期と
  整合する形で計算できる。
- 板の整合幾何の三階微分は存在するが、動径節点で跳ぶ
  （三次 Hermite の三階微分は区間定数のため）。転がりの
  拘束項 Hc に跳びが入るので、振動板への接続時には
  「節点をまたぐイベントとして扱う」等の方針決定が必要。
- 振動する曲面（時間依存）には法線の時間微分タワー
  （∇htt 等）が追加で必要。未実装。
- 飛行→接触の衝突時の角運動量（摩擦インパルス）は未実装。
- 球モデル・粒子間接触なしという限界は M6-15 と同じ。

## 次の候補

1. 時間依存曲面への拡張（微分タワーの設計と、上下振動する
   曲面での検証可能な条件の構築）。
2. 衝突時の摩擦インパルスと回転の接続（着座⇄飛行）。
3. 節点での三階微分の跳びをイベントとして扱う設計、または
   より滑らかな動径補間（五次 Hermite 等）の精度評価。
