# M6-7（PR #10）最終監査記録

対象: PR #10 `m6-7-fastpath`（監査時点 HEAD `435bc1e`、その後本記録のみ追加）

## 独立監査の結果

- `heightAccelAt` / `accelAt` / `heightAtFused`: Hermite 係数式
  （A〜D、P/Q/Rr/Ss）、動径ビン、三角漸化、和の順序が `surfAt` /
  `modalCoeffs` と同一であることを差分で確認。ビット一致テストが
  ランダム点・境界点・板の外側・区間端点の時刻で固定されている。
- キャッシュ: 高さ専用・高さ+加速度専用の係数キャッシュはいずれも
  `beginStep` で無効化される。スライス範囲キャッシュはセグメント
  同一性で鍵付け。周波数・楽譜変更では新しいセグメントになるため
  古い値の混入経路はない。
- 着座判定の置換: 必要なのは高さと加速度だけで、離脱の瞬間は
  従来どおり全量評価（板速度が必要）。物理量の欠落はない。
- M6-5R の境界修正（適用域・失敗時の安全側処理）は本 PR の差分でも
  維持されている。局所休止の二段階判定は、開始点が正方形の外に
  ある場合も含めて安全側に倒れることをコード上で確認した
  （外接矩形の上限が無限大となり休止しない）。
- `localSleep` は既定 OFF。Worker の生成経路は指定していない。
- 計測カウンタ（評価回数など）は読み取り専用の診断情報で、
  制御には使われていない。追加メモリは係数キャッシュ数十 KB 級。
- ベンチの比較条件（粒子数・物理時間・seed・駆動力）は前後で同一。
  絶対時間は計測セッション間で変動するため、文書では倍率と
  カウンタ（評価回数・衝突回数、セッション不変）を併記している。
