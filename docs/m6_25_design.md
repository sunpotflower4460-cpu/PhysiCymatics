# M6-25 設計 — 板上面の物質点運動（キルヒホッフ補正）

## 背景

現行モデルでは板の物質点は鉛直にしか動かない (0,0,ht)。
しかし曲げ板（キルヒホッフ理論）では、上面（z=+H/2）の
物質点は水平変位 u = −(H/2)·∇w を持ち、水平速度
−(H/2)·∇(∂w/∂t) で動く。本リポジトリの板厚は H=1mm
（reference/plate_transient.py の H_PLATE）。大きさの見積もりは
約 1mm/s で、ドリフト速度と同程度。摩擦と滑りの基準が
変わるため、M6-24 で測った整流ドリフトに影響し得る。

## 導入範囲（線形板理論の範囲内）

- 上面の位置: S = (x − ht2·hx, y − ht2·hy, h + ht2)、
  ht2 = H/2。その偏微分は既存の微分タワーで足りる。
- 法線は中立面のグラフ法線を維持する（上面法線との差は
  O(H・曲率) で、線形理論の近似として明記）。
  これにより法線分離などの既存の導出構造は
  O(ht2・傾斜・曲率) の近似として維持される。
- 滑り速度の基準（板物質点速度）が S_t に変わる。
  式の形 u = J·q̇ + R·n̂_t − R(ω×n̂) は不変で、
  J, A0, K の中身が上面偏微分に置き換わる。
- 衝突（M6-18）でも板速度を S_t にする。
- 既定は ht2=0（従来モデルと同一）。研究経路でのみ有効化。

## 検証

1. 上面ありの中心偏微分を有限差分と照合。
2. ht2=0 で既存テストが不変（回帰）。
3. ドリフト場（M6-24 と同条件）を ht2=0.5mm で再測定し、
   上り勾配ドリフトが弱まる・反転するかを見る。
