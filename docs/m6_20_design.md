# M6-20 設計 — 輸送の機構分解と振動分布との照合

## 問い

M6-19 で転がり球の水平輸送（点粒子の約240倍）を実測した。
今回はその内訳と意味を調べる。

1. 輸送は「転がっている区間」と「衝突の摩擦インパルス」の
   どちらが支配的か。
2. 砂の行き先は板の振動分布（活動度）と関係するか。
3. 周波数・駆動位置・摩擦係数への感度はどうか。

活動度は結果を測る指標であり、砂を動かす力には使わない。

## 分解の定義（粒子ごと、水平成分）

- 飛行変位 / 接触変位: 各フェーズで進んだ水平変位ベクトルの和。
  合計は全変位に一致する（保存照合テストで検証）。
- 衝突インパルス: 各衝突での水平速度変化 ΔV の累積。
- 接触インパルス: 各接触区間の前後での中心水平速度の変化の累積。
  重力の水平成分はないため、飛行区間では水平速度は保存し、
  全変化は衝突＋接触の合計に一致する（保存照合）。

## 活動度

同じ駆動の板だけを同じ時間だけ走らせ、格子点ごとに
|wtt|（板の加速度の大きさ）の時間平均を取る。砂の初期位置と
最終位置での活動度を比べる。節線そのものではなく連続量で測る。

## 条件

- 機構分解: 152Hz、偏心駆動、8 粒、2 秒、両モデル（M6-19 と同条件）
- 分布: 転がり球 16 粒、5 秒、152Hz 偏心
- 感度: 152Hz 中心駆動、649Hz 偏心（1 秒）、μs=0.1 / 0.6（152Hz）

係数は仮値。claim-tier: 全て measured（本ハーネス内）。
