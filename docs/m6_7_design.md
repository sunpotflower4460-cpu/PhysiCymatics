# M6-7 設計: 初期局面と着座・休止の評価削減

前提: M6-5R / M6-6 を main へ統合済み。物理モデル・接触探索・休止
保証の意味は変更しない。各候補は独立に実装・検証・採否判定する。

## プロファイルで判明した支配項（初期局面）

600,000 粒・弱駆動・物理 0.02 s（全粒が落下して 1 回跳ねる局面）:

- 板高さ評価 2,580 万回が最大の単一コスト。内訳は二分探索が
  1,800 万回（接触 1 件あたり 30 回固定）、残りが 8 点サンプル。
- 全量評価 `surfAt` は接触確定の 60 万回のみ。
- 飛行休止は既に効いており、全粒子ステップの約 85% を省略している
  （休止なし比）。落下そのものはほぼタダで、重いのは接触の解決。
- 単位コスト実測: `surfAt` 358 ns / `heightAt` 213 ns /
  融合版 181 ns / 高さ+加速度 266 ns / キャッシュ命中時 133 ns。

形成後（5,000 粒・弱駆動）は接触のサンプル＋二分探索と、着座粒子の
毎ステップ評価（従来 `surfAt` 2 回/ステップ）が支配的。

## 候補

### M6-7A: 二分探索向け融合高さ評価

二分探索の時刻は粒子ごとに固有で係数キャッシュが命中しない。
Hermite 係数をループ内で直接計算する融合版 `heightAtFused` を
二分探索だけに使う。演算式は同一でビット一致。サンプル評価は
時刻を共有するためキャッシュ版 `heightAt` のまま。

### M6-7C: 着座・起床の専用評価

着座の離脱判定は高さと加速度だけを使う。`heightAccelAt` /
`accelAt`（ビット一致）を新設し、毎ステップ 2 回の全量評価を置換。
起床・復元時の高さ取得も `heightAt` へ。接触確定と離脱の瞬間は
従来どおり全量評価（板速度が必要）。

### M6-7B: 飛行休止の局所上限化

飛行休止の判定は板全体の高さ上限を使っていたため、静かな場所の
上を飛ぶ粒子まで休止に失敗していた。先読みウィンドウの厳密な
q 範囲と、軌道が通過するセルの Φ 範囲の区間積で局所上限を作る。
安全側の条件は従来と同型（弾道下限 > 上限 + 余裕）。適用域は
正方形の内側のみ（M6-5R と同じ）。休止の受理は従来休止と同じ
起床・復元経路であり、ビット一致ではなく既存の許容誤差の枠で
検証する。周波数変更時は既存の全起床で無効化される。

## 採用基準

M6-6 と同じ: 物理一致（ビット一致可能なものはビット一致）、
実測で利益があること、高負荷条件で悪化しないこと、旧経路へ
戻せること。効果のない候補は不採用として記録する。
