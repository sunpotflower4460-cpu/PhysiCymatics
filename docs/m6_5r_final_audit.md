## 独立監査の結果

報告書だけでなく実装・テストを読み直し、以下を確認した。

- 適用域: `locallyClear` は外接矩形が閉正方形 `[-a,a]^2` を出る区間を
  一切証明しない。直線区間は外接矩形に含まれるため、区間全体が
  適用域内に収まる場合だけが残るのは正しい。
- 境界上の点: ちょうど ±a の端点は証明可能として扱われ、対応する
  端セルの（微小拡張した）矩形がその点を含む。
- 非有限入力: 座標・下限・上限値のいずれが NaN/Infinity でも
  「証明できない」として従来経路へ戻る。
- キャッシュ鮮度: Φ 範囲は形状のみに依存し周波数・楽譜変更で
  古くならない。セル高さ上限はステップ番号刻印、q 範囲は
  `beginStep` で毎ステップ再計算される。古い範囲の再利用経路なし。
- 着座休止の領域近道: 正方形外の着座点では近道を使わず厳密な
  個別評価へ戻るガードが入っている。同種の問題の残存は見つからない。
- テストの検出力: 修正前の 2 ファイル（`transientSand.ts` /
  `plateTransient.ts` を main 版に戻した状態）で M6-5R テストを
  実行し、境界2件が実際に失敗することを再確認した（変異検査）。
- 接触・離脱・消失の既存挙動: 変更は「省略してよい証明」の範囲を
  狭める方向のみで、受理後の物理更新式には触れていない。
  ON/OFF ビット一致テストがこれを固定している。
- 安全余裕の位置づけ: 1e-9 m の余裕と矩形・q 範囲の微小拡張は、
  向き付き丸めによる形式的数学保証ではない。板振幅の規模
  （~1e-3 m）に対する丸め不足（~1e-14 m 級）を覆う工学的余裕と
  して文書化されている。この区別は妥当。

## CI・レビューの確認

- GitHub Actions のワークフロー `physics-truth-ci` は
  `disabled_inactivity`（60日無活動による自動無効化）だったため
  PR に実行結果が付いていなかった。API で再有効化した。
- 再有効化後の実行で 2 件の既存 CI 不具合が表面化し、本ブランチで修正:
  1. `pytest` 単体実行で `reference` パッケージが見えない
     （`python -m pytest` でのみ成功）。`pytest.ini` に
     `pythonpath = .` を追加し、通常の `pytest` でも 75 件通過を確認。
  2. nightly/dispatch 専用 `swift-core` ジョブが macOS ランナーの
     PEP 668（externally-managed-environment）で失敗していた
     （2026年9月から継続する既存問題）。`setup-python` 導入に変更。
- Codex 自動レビュー: 使用量上限により完了せず（Bot 側の失敗で、
  コードの指摘ではない）。CodeRabbit: リポジトリ条件により
  スキップ。代替として本監査記録と、上記の変異検査・包含テスト・
  ON/OFF 一致テストを証拠とする。
