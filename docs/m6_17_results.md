# M6-17 結果 — 振動する曲面上の球転がり

設計: `docs/m6_17_design.md`。実装:
`webapp/src/simulation/rollingDynamic.ts`（研究用、本体未接続）、
板の動的フィールド `surfaceFieldDynamicConsistent`
（`plateTransient.ts`、整合幾何の研究経路内）。

## 実測（measured）

| 検証 | 結果 |
|---|---|
| 中心偏微分（x/y/t、一階・二階）vs 有限差分 | 一階 1e-5、二階 5e-2 以内 |
| 振動する平面斜面の軌道 vs M6-15 平面モジュール（独立実装） | 位置・速度 1e-9、回転 1e-6 以内で一致 |
| 静的極限の円筒槽周期 | 解析値と 1% 以内（M6-16 と同じ） |
| 上下振動する槽底の離脱 | 小振幅では接触維持、大振幅では解析位相 (π/6)/ω で離脱（3e-4 s 以内） |
| 板の動的フィールド: ht のヘッセ・htt の勾配 vs 有限差分 | スケール誤差 0.02 未満 |
| 板の ht vs 高さの時間差分 | 1e-4 未満 |
| 統合スモーク: 駆動される実際の板面上で 1 粒転がり | 200 ステップ（約 30ms）roll 維持、NaN なし |

## 分かったこと・限界

- 時間依存曲面でも法線方程式は分離し（N = n̂·A0 + g·n̂_z）、
  転がり・滑り・離脱を同じ枠組みで扱える。
- 実際の板（整合幾何）の上で転がり計算が最後まで通ることを
  確認した。ただしこれは 1 粒・短時間のスモークであり、
  砂全体の物理の正確さを示すものではない。
- 三階微分の節点での跳び（M6-16）は未解決。転がり計算は
  節点をまたいでも破綻しなかったが（スモーク範囲）、
  厳密な扱いは未定。
- 飛行→接触の衝突時の回転接続、休止保証、粒子間接触は未実装。
  本体接続にはこれらが前提になる。

## 次の候補

1. 衝突時の摩擦インパルス（飛行→着座→転がりの接続）の
   解析検証可能な最小モデル。
2. 三階微分の跳びをまたぐ転がりの精度評価（節点通過イベント化
   の要否判定）。
3. 少数粒子の長時間実験で、転がりが水平輸送に与える影響の測定
   （M6-13 で無視できると分かった滑りとの比較）。
