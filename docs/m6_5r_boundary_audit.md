# M6-5R 監査: 局所非接触判定の境界と数値安全性

対象: M6-5 で導入した `TransientSandSim.locallyClear()` と、その材料
（`cellPhiRanges`、`hermiteQRange`、`segQRanges`、`cellHeightMax`）。
結論: **板の外側（正方形の外）では上限保証が成立していなかった**。
安全側に修正した。物理モデル・接触探索・休止保証の意味は変えていない。

## 1. 発見した問題（境界）

事前計算した Φ の範囲は、正方形 `[-a,a] × [-a,a]`（a=0.12 m）を
64×64 セルに割ったものだけである。一方、実装の `phiAll()` /
`surfAt()` は正方形の外でも値を返し、その値は

- 動径ビン: 最後のビンに固定（r > a でも同じ）
- 角度: 実際の θ

で決まる。修正前の `locallyClear()` はセル番号を端に寄せて
（クランプして）いたため、正方形の外の点に端のセルの範囲を
当てていた。端のセルの角度範囲は外の点の θ を含まないため、
範囲が実装値を包含しない。

実測（監査プローブ、回帰テストに固定）:

- 点 (0.24, 0.05)（開始点 (0.10, 0.05) から外へ出た先）では、
  18 自由度中 16 で Φ の実装値がクランプしたセルの範囲外
  （例: 実装値 0.9168 に対しセル範囲 [0.6612, 0.7167]）
- ランダムに励振した板では、正方形の外で実際の板高さが
  クランプしたセルの高さ上限を最大 1.76e-4 m 上回った

到達可能性: 粒子の生存判定（r > a で消失）はステップ終了時のため、
ステップ途中の区間は正方形の外まで伸び得る。基準経路（サンプル＋
二分探索）は外側でも `surfAt` を評価して接触し得るので、誤った
「非接触」判定は原理的に結果を変え得た。

ただし、実際の誤判定で粒子状態が変わる反例は、探索の範囲では
再現できなかった（2,835 条件＋601 点の細密走査で、正方形の外まで
伸びる区間の省略が 413 件あったが ON/OFF の状態差は 0 件）。
外接矩形全体の上限は区間和で緩く、実際には守られていた可能性が
高いが、**保証としては成立していなかった**ため、結果が偶然に
一致していたことと「証明できていた」ことは分けて扱う。

## 2. 修正

1. **適用範囲の明示**: 区間の外接矩形が `[-a,a]^2` から少しでも
   出る場合は非接触を証明せず、従来のサンプル＋二分探索へ戻す。
   閉境界（ちょうど ±a）は範囲内として扱う（セルは閉矩形で包含）。
2. **失敗時に安全側へ倒す**: NaN・Infinity の入力や上限値は
   すべて「証明できない」として扱う。修正前は NaN の比較が
   素通りし、誤って「非接触」になる経路があった。
3. **セル矩形の微小な拡張**: セル番号の算術（floor）と矩形の端、
   および区間端点とサンプル位置の丸めの差（いずれも 1e-17 m 級）を
   覆うため、各セルの矩形を 1.2e-13 m だけ広げて範囲を事前計算する。
   範囲が広がる方向なので保守性は増す。
4. **時間範囲の微小な拡張**: セグメントの q 範囲（Hermite の厳密な
   極値）を、評価順序の違いによる ulp 級の差を覆う分だけ広げて
   上限計算に使う。`hermiteQRange` 自体は厳密なまま他用途と共有。
5. 着座休止の領域近道（M6-3B）も同種の境界を持つため、正方形の
   外の着座点では近道を使わず厳密な個別評価へ戻すよう統一した。

## 3. その他の監査項目

- **Φ 範囲の包含**: 全 64×64 セル・原点・角度の折り返し・動径ビン
  境界・格子の角について、既存の決定的テストに加え、境界点
  （角・辺の中点・±a の内側 1e-15・ビン境界の半径×複数角度）で
  実際の `surfAt` 高さがセル上限以下であることを追加確認した。
- **Hermite 時間範囲**: 3 次多項式の Bernstein 形式（独立した
  評価経路）と比較し、`hermiteQRange` が稠密サンプルを包含し、
  Bernstein の凸包の内側にあることを 300 試行で確認した。
- **区間積と総和**: セル高さ上限は自由度ごとの区間積の最大の和で、
  数学的には安全側。浮動小数点の丸めで生じる不足は、板振幅の
  規模（~1e-3 m）に対して 1e-14 m 級であり、1e-9 m の余裕と
  上記 3・4 の拡張で覆う。これは「向き付き丸めによる形式的証明」
  ではなく、規模の根拠を明示した工学的な余裕である。振幅が
  桁違いに大きい条件（現行の駆動力では到達しない）では
  余裕の再評価が要る。
- **キャッシュの鮮度**: Φ 範囲は形状のみに依存し、周波数・楽譜の
  変更で古くならない。セル高さ上限はステップ番号で刻印され、
  q 範囲は各ステップの `beginStep` で再計算される。Worker の
  再初期化ではシミュレーション自体を作り直す。古い範囲を
  使い回す経路は見つからなかった。

## 4. 回帰テスト（追加分）

`webapp/src/simulation/__tests__/sleep.test.ts` の
「M6-5R boundary audit」に 7 件:

- クランプした端セルが正方形の外の Φ を包含しないこと（監査証拠）
- 正方形を出る区間を証明しないこと（全方向・境界ちょうどを含む）
- 非有限入力で安全側に倒れること
- 決定的な境界点でセル高さ上限が実際の高さを包含すること
- Hermite 範囲と Bernstein 形式の相互包含
- 外向きに高速な粒子群（縁での消失を含む）で ON/OFF ビット一致
- 周波数切替＋残留振動で ON/OFF ビット一致

修正前は「正方形を出る区間」と「非有限入力」の 2 件が失敗し、
修正後に全て通過する。ON/OFF 一致だけを保証の証拠とはせず、
上限そのものの包含テストを別に持つ（両経路とも現行の接触検出の
限界を共有するため）。

## 5. 性能の再測定

M6-5 と同じベンチ（物理 0.5 s 分、ウォームアップ後の中央値）を
修正後に再実行した。

| 条件 | OFF | ON（修正後） | 倍率 | 省略区間（修正前→後） |
|---|---:|---:|---:|---:|
| 5,000 粒・強駆動 | 9,057 ms | 5,489 ms | 1.65x | 2,495,138 → 2,495,138 |
| 5,000 粒・弱駆動 | 8,009 ms | 7,087 ms | 1.13x | 663,987 → 663,981 |
| 5,000 粒・弱駆動（形成後） | 10,643 ms | 7,489 ms | 1.42x | 2,167,322 → 2,167,322 |
| 20,000 粒・強駆動 | 15,153 ms | 9,645 ms | 1.57x | 3,646,158 → 3,646,158 |

衝突回数は全条件で修正前と完全一致。注目点として、これらの
ベンチ条件では、正方形を出る区間は修正前も実際には省略されて
いなかった（省略件数がほぼ不変。弱駆動の 6 件差は矩形・範囲の
微小拡張による）。つまり不具合は「潜在的に保証が無い」状態で
あり、今回の修正は速度を落とさずに保証を回復した。

## 6. 未保証の範囲（正直な床）

- 本判定の保証は「実装済みのサンプル接触探索が検出する接触を
  減らさない」ことであり、厳密な連続衝突検出ではない。サンプル
  間に完結する浅い接触は従来どおり見逃し得る（M6-1 由来）。
- 余裕 1e-9 m は規模に基づく工学的余裕であり、全入力に対する
  向き付き丸めの形式的証明ではない。
- 保証は現在の独立粒子モデルに対するもの。粒子間衝突や摩擦を
  導入する場合は再監査が要る。
