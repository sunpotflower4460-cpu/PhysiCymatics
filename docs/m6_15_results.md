# M6-15 結果 — 球形粒子の転がり（最小実験）

設計: `docs/m6_15_design.md`。実装: `webapp/src/simulation/rollingSphere.ts`
（研究用 standalone、本体未接続、既定の本番物理は不変）。
検証: `__tests__/rollingSphere.test.ts`（8 件、全て解析照合）。

## 実測（measured、解析解との比較）

一様球 β=2/5、R=1mm、μs=0.3、μk=0.2（係数は検証用の仮値、
プロジェクト実測ではない）。

| 検証 | 解析値 | 結果 |
|---|---|---|
| 静止斜面の転がり加速度 | g·sinθ/(1+β) = (5/7)g·sinθ | 一致（12 桁） |
| 静止（滑らない）境界 | tanθ = μs(1+β)/β = 1.05 | 境界の両側で mode が理論どおり切替 |
| 斜面転がりのエネルギー | KE + g·z_C 一定 | 2 秒間で相対 1e-6 未満の保存 |
| 水平面の純滑り→転がり | 最終速度 v0/(1+β)、遷移時刻 v0/(μk g (1+1/β)) | 一致（速度 6 桁、時刻 2ms 以内） |
| 強いバックスピン | 保存量 C=vx+βR·wy、最終 vx=C/(1+β)（負＝逆転がり） | 一致（6 桁） |
| 上下振動面の離脱 | htt=-g の時刻 (π/6)/ω | 一致（4 桁） |
| 刻み幅収束 | 厳密解へ単調収束、dt=1e-4 で 1e-6 未満 | 確認 |

## 分かったこと・限界

- 転がりの力学（接触力・トルク・滑り遷移・エネルギー）は、
  平面に対しては解析と一致する形で実装できた。
- 実際の振動板は曲面であり、本モデルのままでは使えない。
  曲面への拡張には、中心のオフセット面拘束に h の三階微分が
  必要（M6-14 の整合幾何は二階まで）。これが次の理論課題。
- 実際の砂粒は真球ではなく、粒子同士の接触も未実装。
  球モデルは検証可能な最小形であり、現実の再現とは呼ばない。
- 休止証明は着座位置固定が前提のため、転がりを本体接続する
  場合は再導出が必要（M6-13 と同じ制約）。

## 次の候補

1. 整合幾何に三階微分をどう持たせるか（補間方式の再検討を含む）。
2. 曲面上の球転がりの拘束導出と、球面・円筒面など解析比較が
   可能な曲面での検証。
3. 衝突（飛行→接触）時の角運動量の扱い（摩擦インパルス）。
