前提: M6-7 を main へ統合済み。物理モデル・接触探索（8サンプル＋
30回二分探索）・休止保証の意味は変更しない。

## 支配項（M6-7 プロファイルの続き）

初期局面の支配項は接触解決の高さ評価（サンプル＋二分探索）。
評価1回の内訳は、時刻係数（Hermite）と空間形状（動径ビン・三角
漸化・自由度ループ）である。

## A系統（ビット一致の高速化）

### ライブ自由度マスク

Hermite 端点（q, qd）が全て 0 の自由度は、そのセグメントで
恒等的に 0 であり、高さ・加速度への寄与は厳密な 0。
その項を飛ばしても和はビット一致する（有限な状態を前提。
±0 の加算は有限和を変えない）。
中心駆動（既定）では 18 自由度中 m=0 の 2 つだけが生きるため、
高さ・加速度評価とその係数キャッシュをライブ自由度だけに
限定する。マスクはセグメントごとに端点から再計算され、
周波数・駆動点変更にも自動で追随する。`surfAt` 全量経路は
不変（参照としての役割を維持）。
