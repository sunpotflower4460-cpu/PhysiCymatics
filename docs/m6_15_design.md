# M6-15 設計 — 球形粒子の転がり（最小実験）

## 目的

有限半径・慣性モーメントを持つ粒子の回転運動を、解析解のある条件で
検証する。既存の経験的 `c_roll` とは別物として、力学から導出した
転がりとして実装する。本体（TransientSandSim）へは接続しない。

## モデル（PUT-IN）

- 球: 半径 R、質量 m、慣性モーメント I = β m R²（一様球 β=2/5）。
  以下すべて単位質量あたり。
- 板面: **平面** `h(x,y,t) = hx·x + hy·y + s(t)`（傾き一定、法線一定）。
  曲面・時間変化する傾きでは、中心の拘束に法線の二階微分（h の
  三階微分）が必要になるため本段階では対象外とし、実行時に検査して
  対象外なら例外にする。
- 接触: 垂直抗力 N、クーロン摩擦 f（接線）。トルクは接触点まわり
  `(-R n̂) × f`。法線まわりのスピン摩擦はなし（ω·n̂ は保存）。

## 運動方程式（EMERGED の導出）

一般化座標 q=(x,y)（接触点の板パラメータ）。接線基底
e1=(1,0,hx), e2=(0,1,hy)、M_ij = ei·ej。

- 中心加速度の接線方程式: `M a = Qf − ∇h (g + htt)`（M6-13 と同じ
  拘束。平面では B=htt）。N = (g+htt)/√(1+|∇h|²)、離脱は N≤0。
- 滑り速度: `u = v_t − R (ω×n̂)`、v_t = vx·e1 + vy·e2。
- 角運動: `ω̇ = −(n̂×f)/(βR)`、したがって `d(ω×n̂)/dt = −f/(βR)`、
  `u̇ = v̇_t + f/β`。
- 滑らない転がり (u=0 維持): f = −β·v̇_t となり Qf = −β·M·a、
  よって `a = −(g+htt)/(1+β) · M⁻¹∇h`。
  静止斜面では接線加速度 `g·sinθ/(1+β)`（一様球で (5/7)g·sinθ）。
  必要な静止摩擦は |f| = β·g·sinθ/(1+β)、静止条件は
  `tanθ ≤ μs(1+β)/β`（一様球で 3.5μs、古典的結果）。
- 滑り: f = −μk·N·û。水平面では `v + βR(ω×n̂)_x` が保存し、
  純滑り初速 v0 から転がり速度 v0/(1+β) へ遷移する（古典的結果）。

## 検証計画（解析照合）

1. 静止斜面の転がり加速度 (5/7)g·sinθ、エネルギー保存
   （KE = ½(1+β)|v_t|²、中心高さの低下と一致）。
2. 静止条件の境界 tanθ = μs(1+β)/β。
3. 水平面: 純滑り → 転がり遷移、最終速度 v0/(1+β)、遷移時刻。
4. 逆スピン（バックスピン過剰）: 滑り方向が反転し、最終的に
   逆向き転がりになる条件。
5. 上下振動する水平面: N の符号による離脱、摩擦力の変調。
6. 刻み幅収束。

## 採用条件・限界

- 平面以外（実際の振動板の曲面）への拡張には h の三階微分と
  オフセット面の拘束の再導出が必要。それまでは本体接続しない。
- 実際の砂粒は真球ではない。球モデルは検証可能な最小形であり、
  現実の砂の完全再現とは呼ばない。
- claim-tier: established（古典力学）。数値検証は measured。
