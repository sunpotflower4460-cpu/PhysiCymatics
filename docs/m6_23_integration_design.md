# M6-23 設計 — 転がり物理の本体接続に向けた設計判断

## 目的

M6-13〜M6-22 の研究成果（着座摩擦・整合幾何・転がり・衝突・
粒子間衝突・空気抗力）を、本体シミュレーション
（TransientSandSim）へ接続するための設計と、接続前に
再導出が必要な安全保証の一覧を定める。本書は設計のみで、
接続実装は行わない。

## 現在の本体の前提と、転がりで壊れる点

| 本体の仕組み | 前提 | 転がりでの問題 |
|---|---|---|
| 着座休止 | 着座粒子の水平位置は不変 | 転がる粒は水平に動く。保証再導出が必要 |
| 飛行休止 | 点粒子の弾道と板高さ上限 | 球中心の弾道とオフセット面の隙間で再定義が必要 |
| 局所非接触証明（M6-5） | ビン幾何のセル範囲 | 整合幾何版は radialRangeConsistent から構成可能（未配線） |
| 接触探索 | 点と表面の高さ比較 | 球中心とオフセット面の法線距離に置換が必要 |
| 離脱判定 | wtt < -g | 球では N = n̂·A0 + g·n̂_z ≤ 0（曲率項を含む） |
| イベント上限後の処理 | 点粒子の着座化 | 回転状態を含む捕捉条件の再定義 |
| チェックポイント | 位置・速度・着座状態 | 角速度・接触モードの追加（後方互換つき） |
| Python 参照 | 点粒子の参照実装 | 転がりの Python 参照は未作成（TS のみの研究） |

## 接続方針の候補

A. 既定 OFF の実験スイッチで砂全体を球モデルに切替
   （休止・局所証明は無効化し、参照経路で計算）
B. 休止保証を再導出してから段階的に有効化
C. 本体とは別の研究シミュレータとして独立維持

性能の実測（M6-19）では球モデルは点の約 25 倍/粒であり、
60 万粒目標とは真っ向から競合する。したがって当面は
「少数粒子の物理研究」と「大量粒子の高速計算」を分離し、
接続は A（既定 OFF・保証なしの素朴経路）までを上限とする
判断を推奨する。B は保証の再導出コストが大きく、
現時点の科学的收益（節集積が再現できていない）に対して
見合わない。

## 接続前に必要な科学的判断

1. 節集積が出ない問題（M6-20）の原因候補が未特定のまま
   本体へ入れると、「より正しそうだが現象は再現しない」
   モデルになる。空気の流れ場など不足物理の切り分けが先。
2. 摩擦・反発・抗力係数は全て仮値。実測同定の計画なしに
   本番化すべきでない。
3. 三階微分の節点跳び（M6-16）の扱いが未決定。

## 結論

現時点では本体接続を行わず、研究経路を独立に育てる。
接続に進む条件は「節集積の再現に必要な物理の目星が付く」
または「係数の実測同定方針が定まる」のいずれかとする。
本書はその判断材料として、壊れる保証の一覧と再導出範囲を
固定するものである。
