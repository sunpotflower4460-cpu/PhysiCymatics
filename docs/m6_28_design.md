# M6-28 設計 — 節そのものへの密度と駆動位置の比較

背景: M6-27B で細長い粒は低活動度域の滞在が増えたが、
それは外向きの広がりでも説明できた。本段階では活動度では
なく「節（振動しない場所）そのもの」への近さを測る。

## 測定定義（運動には一切使わない）

- 節集合は粒の運動と独立に、板だけの計算から決める。
  時間平均 |wtt| の格子（49×49）について、円板内の値の
  下位 10% のセルを節セルとする。
- 各粒について、最寄りの節セル中心までの距離を測る。
  格子の粗さ（約 5mm）が距離の分解能の床になる。
- 密度の指標: 節から 2.5mm / 5mm 以内にある粒の割合。
  比較基準（ヌル）は円板内に一様に置いた決定的な格子点で、
  同じ割合を計算する。濃縮率 = 粒の割合 ÷ ヌルの割合。
- 中央値の節距離も併記する（ヌルの中央値と比較）。

## 比較条件

- 駆動位置: 中心 [0,0] と偏心 [0.06,0]。外向き広がりが
  板端の幾何によるものか、活動度の分布によるものかを
  分ける。中心駆動では節は同心円状になるはずで、
  「外へ広がるだけ」では節距離は縮みにくい。
- 形: アスペクト比 1.0（球対照）と 1.5。
- それ以外は M6-26/27B と同一（152Hz、H=1mm、21 粒、
  再現窓 1.5 秒＋暖機窓 [1.8, 3.3] 秒、同一の初期姿勢）。
- 収束確認: 偏心・アスペクト比 1.5 の再現窓を刻み半分で
  再実行し、節指標が保たれるか見る。

## 判定の置き方

- 節への濃縮と言えるのは、濃縮率がヌルより有意に大きく、
  刻みを変えても保たれ、球対照では見られない場合。
- 平均半径の増加だけで節距離が縮む幾何効果は、中心駆動の
  結果とヌル分布で切り分ける。
