# M6-21 設計 — 空気抗力の最小モデルと高周波での輸送消失の切り分け

## 背景

M6-20 で、転がり球は節ではなく中心の高活動度域へ集まった。
実物のクラドニ実験では空気の効果が輸送に重要とされるため、
最も単純な空気抗力（静止空気に対する線形抗力）で輸送が
どう変わるかを測る。結果ありきの係数調整はしない。

## 抗力モデル（PUT-IN、飛行中のみ）

- 並進: a = −γ(V − 0)、γ = 6πηR/m（ストークス抗力、静止空気）
- 回転: ω̇ = −γs·ω、γs = 8πηR/(βm)（粘性トルク）
- 物理推定値（R=0.25mm、石英 ρ≈2600、η=1.85e-5）:
  γ≈0.51 /s、γs≈1.7 /s。代表速度 0.1 m/s で Re≈3 と
  ストークス域の境界付近。二次抗力は次段の課題として記録。
- 空気の流れ場（音響流）自体は計算しない。U=0 のみ。
- 飛行は線形抗力の解析解で進める（γ=0 で従来の弾道に一致）。
- 接触中・衝突瞬間の抗力は無視する（床として明記）。

走査: 抗力なし / 物理推定値 / 5 倍（小さな粒や不確かさの範囲）。

## 高周波での輸送消失の切り分け

衝突ごとの水平インパルスについて、絶対量の和 Σ|ΔVh| と
ベクトル和の大きさ |ΣΔVh| を比べる。比が小さいほど
打ち消し合いが支配的。152Hz と 649Hz で比較する。

claim-tier: 全て measured（本ハーネス内）。抗力係数は
文献的推定であり実測ではない。
