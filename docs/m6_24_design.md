# M6-24 設計 — ドリフト場の診断（節集積が出ない原因の切り分け）

## 問い

M6-20 で転がり球は節ではなく中心の高活動度域へ集まった。
不足物理を足す前に、現行モデル内でドリフトがどう生じているかを
測る。空気の流れ場のような大きな追加は、必要性が切り分け
できてから判断する。

## 測定

1. **ドリフト場マップ**: 独立した単一粒子を多数の開始位置に置き、
   短時間の平均速度ベクトル（純変位/T）を測る。板の活動度
   （|wtt| 時間平均）の勾配と比較する。相関の符号で
   「活動度の高い方へ」「低い方へ」「無関係」を判定する。
2. **衝突の位相偏り**: 衝突が駆動周期のどの位相で起きているかを
   水平インパルス重みで集計する。板が上に凸な位相と下に凸な
   位相で接触が偏れば、傾斜による偏りが時間を平均しても
   消えない（整流効果）ことの証拠になる。
3. **感度**: 反発係数 e（0 / 0.3 / 0.6）と粒径 R（0.1 / 0.25 /
   0.5 mm）でドリフトの向きと大きさがどう変わるか。

活動度・位相は測定専用であり、砂を動かす入力には使わない。
係数は仮値。claim-tier: 全て measured（本ハーネス内）。
