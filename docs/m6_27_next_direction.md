# M6-27 次段階判断書 — 次に調べる物理は「粒の形」

根拠データ: `docs/m6_26_results.md` / `docs/m6_26_data.json`。
判断日: 2026-11-05（M6-26 安定化・再計測の完了時点）。

## 修復後に確定したこと

1. 数値・イベント処理の既知の欠陥を直しても、152Hz 偏心の
   希薄条件では粒は高活動度側へドリフトする（再現列・暖機後・
   放出位相 4 種の全て）。刻みを 1/4 にしても統計は大きく
   変わらない。つまりこの向きは現在の物理モデルの結果で、
   数値誤差の産物とは言えない（測定した範囲で）。
2. 運動の方向相関は 0.95〜0.98 と異常に高い。跳躍のたびに
   方向がほぼ保たれる。球＋クーロン摩擦では、衝突で接線滑りが
   粘着側に飽和し、回転が跳躍をまたいで方向記憶を運ぶため。
3. 板上面の水平運動は実在の弱化効果だが、実板厚 1mm では
   約 11% で、向きを変える主因ではない。
4. 拡散描像（低拡散域への集積、Abramian et al. 2025）は
   現モデルでは成立しない: MSD は超線形で、低活動度域の
   滞在率はほぼ 0%。

## 次に実装すべき一件: 非球形粒の最小モデル

選定理由: 測定された異常は「方向が散らされないこと」に
集約される。実物の砂粒は角があり、重心と接触点のずれ、
向きに依存する慣性、複数接触によって衝突ごとに運動方向と
回転が散らされる。球モデルにはこの散乱機構が原理的に無い。
係数を振っても球の方向保持は消えない（摩擦感度が低かった
M6-20 の結果とも整合）。

最小モデルの候補（設計は M6-27 で確定する）:

- 剛体ダンベル: 等しい 2 球を剛結した粒。状態は重心位置・
  速度・姿勢（クォータニオン）・角速度。接触は各ローブ球と
  板面の間隙で判定し、衝撃は接触点まわりの角運動量保存と
  摩擦インパルスで解く（既存の球衝突の一般化）。
- 球への帰着: ローブ間距離 → 0 で既存の球モデルと一致する
  ことを回帰条件にする。

禁止事項（従来通り）:

- 向きの乱数キック、節位置に依存する散乱、結果に合わせた
  姿勢リセットは入れない。散乱は姿勢と接触幾何から決定的に
  生まれるものだけを使う。
- アスペクト比は「模様が出る値」に調整しない。1.0（対照）、
  1.5、2.0 の感度走査として全結果を報告する。

成否を判定する試験:

1. 解析照合: 自由飛行での角運動量・エネルギー保存、平板への
   衝突での接触点角運動量保存とエネルギー非増加 (e≤1)、
   球極限の再現。
2. 診断の再測定: M6-26 と同一プロトコル（21 プローブ・
   再現窓・暖機窓・方向相関・MSD・滞在率）。
3. 判定基準（事前に固定）:
   - 方向相関が球の 0.95〜0.98 から有意に下がるか。
   - 平均射影の符号と大きさがどう変わるか（下り勾配に
     なれば合格、ではない。機構として散乱が生まれたかと、
     その結果の向きを分けて報告する）。
   - 形を入れても方向相関 >0.9 で上りドリフト不変なら、
     「形は主因でない」と結論し、次候補へ移る。

## 後回しにした候補と理由

| 候補 | 理由 |
|---|---|
| 空気の流れ場（音響流） | 静止空気抗力では向きが変わらなかった (M6-21)。流れ場モデルは大きな未検証の追加で、係数同定の手段も無い。形の結果を見てから判断する |
| 粒子間衝突・堆積の本格化 | 希薄な単粒ドリフト自体が上り勾配で、堆積は別体制。密条件の増幅は確認済みだが、節集積の説明には単粒機構の理解が先 |
| 係数同定（摩擦・反発の実測） | リポジトリ内に実測手段が無い。感度が低かった範囲では向きを変える主因になりにくい。実物実験が可能になった時点で別途 |
| 接触・イベント処理の更なる厳密化 | 刻み収束と位相走査で統計が安定した。残るサンプリング走査の限界は記録済みで、向きの結論を支配していない |
| 本体接続 | 下記の理由で引き続き見送り |

## 本体接続を見送る理由（M6-23 判断の維持）

- 希薄条件で集積方向が節と逆のままで、不足物理の特定が
  完了していない。
- 摩擦・反発・形状係数は仮値のまま。
- 球の計算は点の約 31 倍（8 粒・2 秒で 31.4s 対 1.0s）で、
  休止保証は幾何整合面＋転がりに対して未再導出。
- 今回直したイベント走査は 8 分割サンプリングで、包含保証
  ではない。本体接続の前に保証の再導出が要る。

接続を再検討できる条件: 形の研究で方向散乱の機構が定量的に
掴め、係数の同定方針（実測または文献値の適用範囲の明示）が
立ち、休止保証の再導出計画が作れること。
