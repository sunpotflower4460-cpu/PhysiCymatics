# M6-18 結果 — 衝突（摩擦インパルス）と飛行⇄転がりの接続

設計: `docs/m6_18_design.md`。実装:
`webapp/src/simulation/rollingImpact.ts`（研究用、本体未接続）。

## 実測（measured）

| 検証 | 結果 |
|---|---|
| 粘着衝突（水平面、落下＋横速度） | 解析値と一致（vx→vx/(1+β)、回転は滑りゼロ） |
| 滑走衝突（かすめ衝突） | 法線・摩擦インパルス、残存滑りとも解析値と一致 |
| 接触点まわりの角運動量保存（傾斜面・ランダム 200 件） | 保存（1e-9 相対） |
| 運動エネルギー（同上） | 増えない（全件） |
| 全サイクル: 1cm 落下→滑り衝突→着座滑り→転がり | 最終速度 0.7/(1+β)（保存量経由で解析一致） |
| 粘着衝突後の 2 回目の跳ね返り | 摩擦インパルス不要（滑りゼロのまま再接触）を確認 |
| 飛行⇄転がりの状態変換往復（傾斜面） | 位置・速度が復元（9 桁） |

## 分かったこと・限界

- 飛行・衝突・転がりの 3 状態が、角運動量保存という独立した
  検査を通る形で接続できた。
- 浅い落下では粘着条件を満たさず滑り衝突になる。着座後の
  滑り段階を経ても最終の転がり速度は保存量で決まる。
- インパルス中の滑り反転の厳密扱い（Routh 法）は未実装
  （反転しない範囲にガード。エネルギー不整合は検出されず）。
- 衝突時刻の探索（飛行中の接触検出）は呼び出し側の責務のまま。
  砂シミュレーション本体の接触探索とどう統合するかは未設計。
- 反発係数・摩擦係数は仮値（実測ではない）。

## 次の候補

1. 少数粒子で「飛行→衝突→転がり→離脱」を繰り返す長時間実験を
   実際の板面上で行い、水平輸送が着座滑り（M6-13 で無視できた）
   と比べてどう変わるか測定する。
2. 三階微分の節点跳びをまたぐ転がりの精度評価。
3. 本体接続の設計（休止保証の再導出が前提）。
