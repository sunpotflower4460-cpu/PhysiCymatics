# M6-22 設計 — 粒子同士の衝突（球同士の摩擦インパルス）

## 問い

M6-20 で粒は節ではなく中心側へ集まった。不足する物理の候補の
一つ、粒子同士の衝突が輸送と分布に与える影響を測る。

## 衝突モデル（PUT-IN）

等しい球同士の瞬時衝突。中心 C1,C2、法線 n=(C2−C1)/|C2−C1|、
接触点の相対速度 u = (V1−V2) + R(ω1+ω2)×n。

- 法線インパルス（単位質量、球1への作用）Jn = −(1+e)·u_n/2
- 接線: Δu_t = 2(1+1/β)·Jt。粘着は Jt = −β·u_t/(2(1+β))、
  条件 |Jt| ≤ μs·|Jn|。滑走は Jt = −μk·|Jn|·û_t
  （反転ガード付き、M6-18 と同じ規律）。
- 全運動量と全角運動量（任意点まわり）は内力のため保存。
  エネルギーは e≤1 で増えない。これらを独立に照合する。

## ハーネス接続（近似の明示）

衝突検出は板ステップ境界でのみ行う（dt≈0.15ms、相対速度
~0.1m/s でステップ移動 ~15µm ≪ 直径 500µm のためすり抜けは
起きにくいが、厳密な連続検出ではない）。手順:

1. 全粒を中心表現（位置・速度・回転）に変換
2. 空間ハッシュで重なりペアを列挙、めり込み深い順に逐次処理
   （処理順序依存性あり）
3. インパルス適用後、めり込みを中心座標で半分ずつ分離
   （位置補正はエネルギーを変え得る）
4. 接触中だった粒は、板との隙間と法線速度の条件で接触へ戻す

この近似は研究用であり、本番の接触探索とは別物。
結果は「本ハーネス内で衝突を入れた場合」として記録する。

claim-tier: 衝突式は established、接続方式は近似（interpretive）。
