# M6-27 設計 — 非球形粒の最小モデル（剛体ダンベル、段階 A）

背景と選定根拠: `docs/m6_27_next_direction.md`。
M6-26 の再計測で、球モデルの方向相関が 0.95〜0.98 と高く、
跳躍ごとに方向がほぼ散らされないことが分かった。本段階では
「形があると衝突で方向が散らされるか」を、検証可能な最小の
剛体モデルで切り分ける。

## モデル（PUT-IN）

- 粒 = 等しい 2 つの球（ローブ、半径 r、各質量 m/2）を
  距離 2d で剛結したダンベル。全体の長さ 2(d+r)、幅 2r。
  アスペクト比 = (d+r)/r。d=0 が球の対照。
- 状態: 重心位置 C・速度 V、軸方向の単位ベクトル e、
  角速度 ω。ローブ中心は C ± d·e。
- 単位質量あたり慣性（軸対称）:
  - 軸まわり I_par = β r²
  - 軸に垂直 I_perp = β r² + d²
  （β はローブ球の慣性係数、中実球で 2/5）
- 飛行: 重心は重力のみ。回転はトルクフリーで角運動量
  L = I·ω が保存する。e の運動は de/dt = ω×e、
  ω = I⁻¹(e)·L として L を区間内で固定して積分する。
- 衝突: 接触点 P、法線 n、板の物質速度 Vs が与えられた
  瞬時インパルス。接触点速度 u = V + ω×(P−C) − Vs。
  インパルス J による変化は Δu = K·J、
  K = I₃ − [r]× I⁻¹ [r]×（単位質量、r = P−C）。
  - 法線: Jn = −(1+e)·u_n / (nᵀKn)（接近時のみ）
  - 接線: 粘着インパルスは接線 2×2 系を解いて求める
    （法線との結合 Ktn も含める）。摩擦円錐の外なら
    μk で滑り、接線速度が反転する場合は粘着量で頭打ち
    （球の rollingImpact と同じ規律）。
  - 接触点まわりの角運動量は構成上保存する。

## EMERGED として測るもの

- 同じ入射速度でも、姿勢によって跳ね返りの水平方向が
  散らばるか（球では姿勢が無く散らばらない）。
- 散らばりの大きさのアスペクト比依存（1.0 / 1.5 / 2.0 は
  感度走査であり、模様に合わせた調整ではない）。

## 今回の範囲と限界（正直な床）

- 段階 A は飛行＋単独接触インパルスのみ。持続接触
  （転がり・滑り・両ローブ同時接触）の拘束力学は未実装で、
  板ハーネスへの接続とドリフト再計測は段階 B とする。
- 2 ローブ同時接触（軸が水平な場合など）は未解決。
  本段階の診断では単独接触になる姿勢だけを使う。
- e の積分では区間ごとに単位ベクトルへ再正規化する
  （拘束の射影であり、物理の変更ではない。ドリフト量は
  テストで測る）。
- 係数（μs, μk, e, β）は従来と同じ仮値。実物の砂の形を
  再現したとは呼ばない。
- 姿勢への乱数キック、節依存の散乱は入れない。散乱は
  姿勢と接触幾何から決定的に生まれるものだけ。

## 検証計画

1. 球極限 d=0 で既存の球衝突の解析式と一致。
2. 衝突で接触点まわりの角運動量が保存し、e≤1 で
   エネルギーが増えない（決定的な複数ケース）。
3. トルクフリー飛行で L とエネルギーが保存し、軸の
   歳差周期 2π·I_perp/|L| と一致。
4. 軸が鉛直な落下では有効半径 (d+r) と I_perp から
   解析的に出る跳ね返りと一致。
5. 散乱診断: 平板への単独衝突で、姿勢グリッドに対する
   出射方向の広がりをアスペクト比ごとに実測。
