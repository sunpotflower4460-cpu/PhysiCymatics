# M6-18 設計 — 飛行⇄転がりの衝突接続（摩擦インパルス）

## 目的

空中を飛ぶ球が板に衝突する瞬間の、速度と回転の変化を力学から
求め、転がり状態（M6-17）へ接続できるようにする。本体未接続。

## 衝突モデル（PUT-IN）

- 剛体球の瞬時衝突。接触点の相対速度
  u = V + ω×(−R·n̂) − v_板、v_板=(0,0,ht)。
- 法線インパルス（単位質量）Jn = −(1+e)·u_n（e は反発係数、
  u_n<0 が接近）。u_n≥0 なら衝突なし（separating）。
- 摩擦インパルス Jt（接線）による変化:
  ΔV_t = Jt、Δω = −(n̂×Jt)/(βR)、よって **Δu_t = Jt·(1+1/β)**。
- 粘着衝突（衝突後に滑りゼロ）: Jt = −β·u_t/(1+β)。
  成立条件 |Jt| ≤ μs·Jn。
- 滑走衝突: Jt = −μk·Jn·û_t（インパルス中の滑り方向一定の
  標準近似）。ただし滑りが途中で止まる場合は粘着側へ切り替える
  （μk>μs の入力でも滑りの反転を起こさないガード）。

## 保存量（検証の軸）

接触点まわりの角運動量 L = R·n̂×V + βR²ω は、インパルスが
接触点に作用するため保存する。運動エネルギーは e≤1 で
増えない。これらを実装とは独立に数値照合する。

## 状態変換

- 飛行→転がり: 中心位置から接触パラメータ (x,y) を反復で解き、
  Ċ = J·q̇ + C_t を最小二乗（接線射影）で q̇ に変換。
- 転がり→飛行: C と Ċ をそのまま使う（M6-17 の評価）。
- 衝突時刻の特定（飛行中の接触探索）は呼び出し側の責務とし、
  本モジュールは「接触した瞬間の状態」を受け取る。

## 限界

- インパルス中の滑り方向反転の厳密扱い（Routh 法）は未実装。
  上記ガードの範囲でエネルギー的に矛盾しないことを検証する。
- 反発係数・摩擦係数は仮の入力値であり実測ではない。
- claim-tier: 導出は established、数値照合は measured。
