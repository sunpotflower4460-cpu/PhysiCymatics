# M6-7 結果: 初期局面プロファイルと評価経路の削減

前提: M6-5R / M6-6 を main へ統合済み（PR #8 / #9）。比較対象は
M6-6 マージ後の main 標準設定。設計は `docs/m6_7_design.md`。
再実行方法:
`PHYSI_BENCH=1 npx vitest run src/simulation/__tests__/bench_m67.test.ts`
（`PHYSI_BENCH_CASES=initial|formed`、`PHYSI_BENCH_MODES=base,locsleep,...`
で絞れる。結果は `webapp/bench_m67_out.txt`、コミット対象外）

## プロファイル（支配項）

評価回数カウンタを常設し、初期局面と形成後を分けて測った。

600,000 粒・弱駆動・初期 0.02 s（全粒が 0.5 mm から落下し 1 回跳ねる）:

- 板高さ評価 25.8M 回が最大の単一コスト。内訳は二分探索 18M 回
  （接触 1 件あたり 30 回固定）と 8 点サンプル約 7.8M 回。
- 全量評価は接触確定の 600k 回のみ。
- 飛行休止は既に全粒子ステップの約 85% を省略しており、落下そのものは
  安い。重いのは接触の解決である。
- 単位コスト: `surfAt` 約 330〜630 ns、`heightAt` 約 194〜262 ns、
  融合版 181 ns、高さ+加速度 266 ns、キャッシュ命中時 133 ns
  （計測セッションで変動）。

形成後（5,000 粒・弱駆動、0.5 s 窓）: 高さ評価 18.8M 回（二分探索
7.1M）、着座ステップ 1.8M 回。休止による省略は粒子ステップの約 62%。

## 採用したもの

### M6-7C: 着座・起床の専用評価

着座の離脱判定（毎ステップ、全量 `surfAt` 2 回）を、高さ+加速度だけの
`heightAccelAt` / 加速度だけの `accelAt` に置換。起床・復元時の高さ
取得も `heightAt` へ。いずれも `surfAt` の該当成分とビット一致を
テストで固定。20,000 粒・強駆動では全量評価が 4.72M → 0.36M 回に減った。

### M6-7A: 二分探索向け融合高さ評価

二分探索の時刻は粒子ごとに固有で係数キャッシュが命中しないため、
Hermite 係数をループ内で直接計算する `heightAtFused` を二分探索に
採用（ビット一致）。サンプル評価は時刻共有でキャッシュが効く
`heightAt` のまま。

合わせた効果（同一ベンチ内の前後比較、中央値）:

| 条件 | M6-6 時点 | M6-7 後 | 変化 |
|---|---:|---:|---:|
| 600,000・弱・初期 0.02 s（単回） | 15,671 ms | 11,058 ms | -29% |
| 100,000・弱・初期 0.05 s（単回） | 9,160 ms | 6,039 ms | -34% |
| 20,000・強・0.2 s | 8,393 ms | 7,274 ms | -13% |
| 5,000・強・0.5 s | 4,665 ms | 4,106 ms | -12% |
| 5,000・弱・形成後 0.5 s | 5,666 ms | 5,293 ms | -7% |

注: 前後で計測セッションが異なる行があり、絶対値は機械負荷で
変動する。評価回数・衝突回数・離脱回数は前後で一致しており、
物理経路は変わっていない。600,000 粒・初期は物理 1 秒あたり
約 550 秒相当で、リアルタイムには約 2 桁以上の差が残る。

## 採用しなかったもの

### M6-7B: 飛行休止の局所上限化（既定 OFF で残置）

先読みウィンドウの厳密な q 範囲と通過セルの Φ 範囲で局所上限を作り、
休止を長くする方式。包含テストと物理一致（回数一致＋位置差は既存の
休止同等の水準）は確認した。省略できる粒子ステップは増えた
（例: 5,000・強で +21%）が、判定コストが上回った:

| 条件 | 全体上限（従来） | 局所上限 | 変化 |
|---|---:|---:|---:|
| 600,000・弱・初期（単回） | 11,058 ms | 14,293 ms | +29% 低速 |
| 100,000・弱・初期（単回） | 6,039 ms | 6,935 ms | +15% 低速 |
| 20,000・強・0.2 s | 7,274 ms | 7,154 ms | -2%（誤差級） |
| 5,000・弱・形成後 | 5,293 ms | 5,389 ms | +2% 低速 |

理由: 全体上限の休止が既に落下ステップの大半を省略しており、
局所化で増える省略は数 % に留まる一方、粒子ごとの判定（開始セルでの
二分探索＋通過範囲の走査）が毎回発生する。`localSleep` オプション
として残し、既定は従来の全体上限とする。

### その他

- 着座粒子の空間キャッシュ（位置固定の形状値を保持）: 60 万粒で
  数十 MB の追加メモリに対し、形成後で数 % の見込みのため見送り。
- ブロック単位の上限共有: 上限計算は全体の数 % で複雑さに見合わない。
- GPU: Float64 参照との一致検証が先。今回は扱わない。

## 物理の一致

- `heightAccelAt` / `accelAt` / `heightAtFused`: `surfAt` の該当成分と
  ビット一致（テスト固定）。採用した変更はすべてこの性質の上にあり、
  既定経路の粒子状態は従来とビット一致する。
- 局所休止（不採用）: 衝突・離脱・生存数は基準と一致。位置差は
  従来休止と同水準（周波数切替ケースで全体休止との差 1.0e-7 m、
  休止なしとの差 1.4e-5 m は M6-2 休止自体の丸め差が支配的）。
- 浅い接触の検出限界（8 サンプル方式）は不変。粒子間衝突・反作用は
  未計算のまま。

## テスト・未検証

- Web 71 件通過（ベンチ 2 件は環境変数なしでスキップ）、ビルド成功。
- Python: 参照実装は無変更。
- ブラウザの Worker 同時実行は M6-6 時点で実測済み。本段階の変更は
  計算経路の内部置換のみで、ブラウザ再計測は行っていない。
- スマートフォン実機・音声実聴は未検証（従来どおり）。

## 次に必要な研究（効果順の見立て）

1. 接触解決そのものの量: 初期局面では接触 1 件あたり約 37 回の
   高さ評価が支配的。二分探索回数は参照実装との一致のため固定で、
   減らすなら物理精度の研究として分けて評価する必要がある。
2. 高さ評価のさらなる軽量化: 動径ビンと方向余弦の再利用は着座・
   同一粒子内では可能だが、ビット一致の制約とメモリの釣り合い。
3. 休止判定の評価コスト削減（全体上限版でも粒子ごとに二分探索を
   行っている。解析的に解ける形への置換）。
4. GPU 実験経路の設計（Float64 参照との差分検出を先に作る）。
