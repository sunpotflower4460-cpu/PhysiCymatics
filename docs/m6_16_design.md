# M6-16 設計 — 静的曲面上の球転がり

## 目的

M6-15 の平面転がりを、静止した曲面 `z=h(x,y)` へ拡張する。
振動する板（時間依存）への拡張は、法線の時間二階微分など
追加の微分タワーが必要なため次段階とする。本体未接続。

## 拘束の導出（PUT-IN: 球・静的曲面・クーロン摩擦）

接触パラメータ q=(x,y)、表面点 S=(x,y,h)、単位法線 n̂、
球中心 C = S + R·n̂。

- Ċ = J·q̇（J の列は C_x, C_y、いずれも接線方向）
- C̈ = J·q̈ + Hc(v,v)、Hc = C_xx vx² + 2C_xy vx vy + C_yy vy²
- C の二階偏微分には n̂ の二階偏微分、すなわち **h の三階微分**
  （hxxx, hxxy, hxyy, hyyy）が必要。
- 運動方程式（単位質量）: C̈ = −g·ẑ + N·n̂ + f、ω̇ = −(n̂×f)/(βR)
- J の列は法線に直交するため、法線成分は分離する:
  **N = n̂·Hc + g·n̂_z**（摩擦・q̈ に依存しない）。離脱は N≤0。
- 滑り速度 u = Ċ − R(ω×n̂)。その時間変化は
  u̇ = J·q̈ + Hc + f/β − R(ω×n̂̇)（接線成分）。
- 転がり（u=0 維持）: 接線方程式 JᵀC̈ による 2 本と u̇=0 の
  接線 2 本を連立し、未知数 (q̈, f) の 4×4 線形系を解く。
  静止摩擦が足りる条件 |f| ≤ μs·N で転がり成立。
- 滑り: f = −μk·N·û を先に決め、接線方程式から q̈ を解く。
- 滑り開始方向: u̇ は f のアフィン関数で u̇(f_req)=0 だから、
  f=0 で評価した u̇ の方向が滑り出し方向になる。

## 検証計画

1. 中心 C の偏微分（実装内部）を、C を直接計算した有限差分と照合。
2. 円筒槽（半径 Rc）での小振動周期 T = 2π√((1+β)(Rc−R)/g)。
3. 放物面・正弦面でのエネルギー保存と滑りゼロの維持、刻み収束。
4. 凸面（丘）での離脱: 遅ければ接触維持、速ければ頂点付近で離脱。
5. 平面極限で M6-15 の結果と一致（斜面加速度）。

## 板の三階微分について

M6-14 の整合幾何は動径三次 Hermite なので、R̂''' は区間ごとに
定数（節点で不連続）として存在する。本段階では板側に三階微分の
評価を追加し、ヘッセ行列の有限差分と照合する。節点での不連続は
転がりの Hc に跳びを作るため、振動板への接続時に扱いを決める
（本段階では接続しない）。
