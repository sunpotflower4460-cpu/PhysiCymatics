# M6-27B 設計 — ダンベル粒の持続接触と板サイクル

段階 A（`docs/m6_27_design.md`）の飛行＋単独衝突に、持続接触を
足して振動板の上でドリフトを測れるようにする。研究経路のみ。
既定の本番物理は不変。

## 接触の扱い（PUT-IN として明示する近似）

球の転がりモジュール群のような拘束 ODE の厳密解法ではなく、
**インパルス型時間刻み**を採用する。これは近似であり、
次を正直な床とする:

- 接触区間を板ステップの 1/4 の小ステップに分ける。
  各小ステップで重力と自由回転で姿勢・位置を進め、
  その後に接触インパルスを解く（演算子分割、誤差は
  小ステップ幅に対して一次）。
- めり込みは重心を法線方向へ戻す位置補正で解消し、
  補正変位は物理的な飛行・接触変位と別に記録する。
- 離脱の検出は小ステップ解像度（板ステップの 1/4）。
  球モデルのような二分探索による時刻特定はしない。
- 摩擦は各小ステップのインパルスで粘着/滑りを判定する。
  静止摩擦で保たれる転がり・ピボットは、接線接触速度を
  ゼロにするインパルスの積み重ねとして生まれる。

## 接触幾何

- ローブごとに球と同じオフセット中心の間隙を使う
  （`solveContactParams` + `dynCenterPartials`、上面補正
  ht2 を含む。M6-26 で統一した定義）。
- 接触点は上面点、法線は板法線、板の物質速度は上面速度。
- 飛行中の接触探索は 8 サンプル＋二分探索（球ハーネスと
  同じ浅い接触の限界を共有）。
- 衝突は段階 A の `dumbbellImpact` を使う。捕捉条件は
  反発後の法線相対速度が g·dt 以下で、球と同じ規律。
  接触区間に入った後は、接触ステップが時間を消費してから
  離脱判定するため、ゼロ時間の捕捉⇄離脱ループは起きない。

## 1 ローブ / 2 ローブ接触

- 接触インパルスはローブごとに深い順へ逐次適用し、
  最大 8 周回して両ローブの法線速度条件を満たす
  （逐次インパルス。適用順序への依存は残る近似として明記）。
- 新しく接触したローブの入り込み速度が大きい場合は
  反発係数ありの衝突として解き、既に接触している
  ローブには反発なし（e=0）の持続インパルスを使う。
- 両ローブとも間隙が開き、分離速度が正なら離脱。

## 検証計画

1. 静止平板（力をゼロにした実板モデル）:
   - 軸水平で両ローブ接触したまま静止を保つ。
   - 軸まわりに転がる配置（軸が進行方向に直交）で、
     球と同じ滑り→転がり遷移後の速度 v0/(1+β) になる。
   - 45° で 1 ローブ支持から倒れ、他ローブが着き、
     全機械エネルギーが増えない。
2. 駆動板のスモーク: 有限値、未消費時間ゼロ、衝突と
   離脱が起きる。
3. ドリフト再計測は M6-26 と同一プロトコル（21 プローブ、
   再現窓 1.5 秒＋暖機窓、活動度射影、方向相関・MSD・
   滞在率）。姿勢の初期条件は決定的グリッドで与え、
   アスペクト比 1.0 / 1.5 / 2.0 を感度走査として全て報告。
